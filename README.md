# Detección de especies forestales con imágenes de dron - CITEforestal Maynas

Detección de especies forestales en imágenes de dron mediante bounding boxes con LibreYOLO.

## Descripción

Este repositorio implementa un pipeline de detección de objetos aplicado a imágenes capturadas por dron para la identificación de especies forestales en la Amazonía peruana. Utiliza [LibreYOLO](https://github.com/LibreYOLO/libreyolo), una librería de visión por computadora con licencia MIT.

## Requisitos

- Python 3.9+
- LibreYOLO
- OpenCV
- NumPy

## Instalación

```bash
pip install libreyolo opencv-python numpy
